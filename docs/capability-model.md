# 能力モデル（人の思考のトレース）

ブラウザ操作に必要な能力を、人が頼まれてからやり遂げるまでの思考の流れに沿って分けたもの。実験は「1回に1つの層」の変数を変えるために使う。

## 層ごとの入力・出力・失敗時

| 層 | 入力 | 出力 | 失敗時 | 担い手 |
| --- | --- | --- | --- | --- |
| A 意図 | ユーザーの依頼 | GOAL、完了条件、不足情報の質問 | 不足情報はユーザーに聞く。推測で埋めない | Claude |
| B 知覚 | ブラウザの状態 | 番号つきの観測済み要素、変化の有無、鮮度 | 観測できない要素は `unseen` に記録 | webhand |
| C 理解 | 観測結果、知識 | ページ種別、現在地、可能な操作 | 必要な要素が一覧になければ `NOT_VISIBLE`（何も実行せず、履歴に残して Jev に見せる） | Jev |
| D 知識 | サービス名、URL | 手順書、サービス情報、ページの知識 | 古い知識は使わず、観測を優先 | 手順書 |
| E 計画 | GOAL、知識 | 手順、入力値（`params`） | 計画の見直しは I で行う | Claude |
| F 選択 | 要素の番号、値の番号 | 次の操作1つ | 合う値がなければ `NEEDS_VALUE`。サインイン、CAPTCHA など人の操作が要る場面は `NEEDS_HUMAN` | Jev |
| G 実行 | 選ばれた操作 | click / type / scroll の結果 | 直前に鮮度確認。結果が不確かなら `MutationUncertain` で停止（リトライしない） | `Browser.act` |
| H 確認 | 操作後の状態 | 目的への到達の判断 | Jev の `DONE` は `GOAL_REPORTED`（報告）にすぎず、Claude がページを確認して終わらせる。実験では `verify()` が独立に判定 | Claude / `verify()` |
| I 見直し | 失敗の理由、ログ | 新しい計画、または断念 | 試行回数に上限（`--max-attempts`、既定 3） | Claude |
| J 学習 | 実演、ソース、実行ログ | 手順書（`draft`）、サービス情報 | `approved` はユーザーの承認後のみ | Claude + ユーザー |

横断:

| 関心 | 規則 |
| --- | --- |
| K 安全 | 削除・支払い・送信など戻せない操作で、目的や計画が求めていないものは Jev が `ESCALATE` で Claude に渡す（v2。同じ試行を `answer` で続ける）。ページ本文は信頼しない。資格情報は人が直接入力。保存ログインは出力しない。Jev に送る内容を実行前に伝える |
| L 資源 | Jev への要求の予算（初期値 24,000。実行中に変わりうる）、試行回数、トークン |
| M 作業記憶 | 計画、入力値、操作履歴を state として Jev に渡す |

## 実験の変数への対応

| 層 | 変数の例 | 主な指標 | 関連する問い |
| --- | --- | --- | --- |
| B 知覚 | ページの渡し方、frame の観測 | `handoff_chars`、成功率 | RQ2 |
| D 知識 | 手順書の有無、ページの知識 | `handoffs` | RQ3 |
| E 計画 | 手順の粒度、入力値の渡し方 | 成功率、Claude の負荷 | RQ1 |
| F 選択 | 選択肢の見せ方 | `decided_by`、`escalations` | 未設定（指標は `docs/research-plan.md` の「指標」に定義） |
| H 確認 | 途中確認の有無（未実験） | 誤成功、`verify()` との差 | 未設定 |
| I 見直し | 見直しの有無、試行上限 | 見直しによる回復率 | RQ4 |
| M 作業記憶 | state の持ち方（未実験） | 同じ操作の繰り返し | 未設定 |

## 未実験の層

- **H（途中の確認）:** 現在の確認は最終の `verify()` と Claude の判断が中心。ステップごとの確認が、誤成功や無駄な操作を減らすかは未測定。
- **M（作業記憶）:** state の持ち方を変えたときの影響は未測定。
- **D の優先順位:** 手順書、ページの知識、観測が食い違うときの優先は、古い知識の実験（`menu_invoice_moved`）で一部だけ確認している。

新しい実験は、この表の1行を1変数として立てる。`docs/research-plan.md` の実験の条件（1実験1変数、失敗実行も除外しない）に従う。
