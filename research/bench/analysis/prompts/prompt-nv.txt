次の回のセッションを対象にします。webhand は、Claude が計画し、Jev がブラウザを操作するエージェントです。
~/webhand-bench/work-sa/* と ~/webhand-bench/work-sb/* のうち、home/runs/*/*.jsonl に type が not_visible のイベントがある
セッション（invalid というファイルがあるものは読まない）。

not_visible は、Jev が「次の操作に必要な要素が一覧にない」と答えた出来事です。イベントの wanted（操作）と offered
（一覧に出た要素の数、省略の数、見えない領域の数）と、その前後の step と page のイベント、
~/webhand-bench/work-*/<ID>/home/ 以下のスクリーンショット（あれば）を読み、各 not_visible について
「必要だったはずの要素が、なぜ一覧になかったか」を、タスクに依存しない型で判定してください。

型（主なもの1つ）:
 1. canvas や iframe（frame）の中にある、または描画された絵で、DOM の要素ではない
 2. 押せる見た目だが、標準の要素・役割がない（div や span の onclick、独自の部品）で、一覧に出なかった
 3. 別の操作のあとに初めて現れる（メニュー、ドロップダウン、日付ピッカー、ポップアップ、ホバー、入力後）
 4. 別のタブ・ウィンドウ・ページにある（今のページにはない）
 5. 画面を覆うもの（Cookie の同意、ダイアログ）の下にあり、一覧に出なかった
 6. 一覧の大きさの上限で省略された（offered の omitted_actions、omitted_reveals が 0 でない）
 7. 読み込み中で、まだ出ていない（遅延読み込み、スクロールで追加される一覧）
 8. その要素はページに存在しない（計画の前提が違う、サイトの作りが違う）
 9. 判定できない／その他

あわせて、各セッションについて、同じ not_visible が続いたあとの動き（Claude が replan、answer、act、別の入口、
利用者への質問のどれをしたか）と、それで要素が見つかったか（見つかった／見つからなかった）を数えてください。

型ごとに件数（イベント数とセッション数）と、該当するタスク ID と sa/sb だけを書いてください。最後に、
「タスク ID / sa のイベント数 / sb のイベント数 / 主な型」の表を書いてください。
- タスク文、ルーブリック、サイト名、URL、具体的な値、ページの文章は書かないでください。
- judge の出力（results-*/ 以下、judge/）は読まないでください。この調べには要りません。
- 結果は ~/webhand-bench/analysis/not-visible-sa-sb.md に日本語で書いてください。ほかのファイルは作らないでください。
